# 🍽️ Foodie – Food Delivery Website

A responsive food delivery landing page built using **HTML5, CSS3, Flexbox, Grid, animations, and media queries**.  
The layout is inspired by modern food delivery platforms and includes hero content, category browsing, featured restaurants, promo offers, customer testimonials, and an app download section.

---

## 📌 Sections Implemented

### 1. **Header & Navigation**
- Logo + navigation links + login/signup buttons  
- Becomes stacked and centered on smaller screens  

### 2. **Hero Section**
- Left text block with CTA button  
- Right food image  
- Includes smooth animations  

### 3. **Search Bar**
- Location input + category dropdown + search button  

### 4. **Browse by Category**
- Grid of categories (Pizza, Burgers, Sushi, Indian, etc.)  
- Hover effects and icons  

### 5. **Featured Restaurants**
- CSS Grid used for restaurant cards  
- Includes rating stars and hover scale animations  

### 6. **Promo Offers**
- Three promo cards with icons  
- Light pastel background  

### 7. **Customer Testimonials**
- Card layout with user images and reviews  
- Soft shadow + hover lift animation  

### 8. **App Section**
- Phone mockup image + download buttons  
- Floating animation  

### 9. **Footer**
- Links + contact info + copyright  

---

## 📱 Breakpoints Used

The project uses **three required breakpoints**:

| Device | Breakpoint | Behavior |
|--------|------------|----------|
| **Desktop** | ≥1024px | Multi-column layout, grid + flex side-by-side |
| **Tablet** | ~768px | Stacks sections vertically, centers elements |
| **Mobile** | ≤480–600px | Single-column layout, full-width buttons, compressed spacing |

### Techniques Used
- **Flexbox** → header, hero section, app section, promo section  
- **CSS Grid** → featured restaurants, testimonials  
- **Media Queries** → responsive design for all sections  
- **CSS Transitions** → hover animations on cards & buttons  
- **Keyframe Animation** → floating effect for app
