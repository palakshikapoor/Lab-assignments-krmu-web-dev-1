Lab 3: One-Page Responsive Portfolio Website

---

**Description**

This lab project is an improved version of Lab 2, upgraded using modern CSS features such as Flexbox, CSS Grid, media queries, transitions, and animations.  
The goal is to build a clean, responsive, one-page portfolio that includes the following sections:

- Header  
- Hero  
- About  
- Skills  
- Projects  
- Contact  
- Footer  

The website uses Flexbox for layout structures (header, hero, and projects section), CSS Grid for the Skills section, and keyframe animations for interactive visual effects. Hover transitions are added to buttons, links, and cards for a polished look. Media queries ensure the layout adapts smoothly to mobile, tablet, and desktop devices.

---

**Steps to View Responsive Behavior**

To test the website’s responsiveness, follow these steps:

1. Open **index.html** in any modern web browser (Chrome, Firefox, Edge, Safari).
2. Right-click anywhere on the page and select **Inspect** (or press `Ctrl + Shift + I`).
3. Click on the **Toggle Device Toolbar** icon (or press `Ctrl + Shift + M`).
4. Test the website using the following screen widths:

### 📱 **Breakpoints Tested**
| Device Type | Width Range |
|-------------|-------------|
| **Mobile**  | 320px – 480px |
| **Tablet**  | 600px – 768px |
| **Desktop** | 1024px and above |
