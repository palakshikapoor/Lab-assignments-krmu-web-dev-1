JavaScript Console Quiz Game

**A simple interactive quiz game built using core JavaScript. 
The quiz runs entirely in the browser console, asking a series of predefined questions using prompt(), giving immediate feedback with alert(), and displaying the final score 
at the end. 
The project demonstrates the use of arrays, loops, functions, conditionals, and basic input handling in JavaScript. 
It also includes input normalization using toLowerCase() and trim() to ensure accurate answer checking.**
